## III. System Architecture: 2. Cascading Lock & AI-Native Semantic Splitting / 三、 系統技術架構：2. 規則：級聯鎖定與 AI 天然分流（語義分割）

English:
## 🎲 Cascading Lock & AI-Native Semantic Splitting
The interaction logic follows a strict top-down constraint system, processed entirely within the black box of the LLM.

* Cascading Lock Mechanism: When a user clicks "Reroll K", the backend hard-locks all hidden elements from index 1 to K-1. The system then forcefully randomizes and rolls entirely new concepts only for indices K through N. The higher the K value, the more context is preserved, and the higher the investment.
* Dynamic Semantic Splitting: Every time a reroll occurs, the backend sends the modified hidden array back to the LLM. The AI dynamically decides on the fly: "Which elements go to the image prompt, which go to the text caption, and which go to both?"
* The Dynamic Paradox: The UI always looks exactly the same, but the underlying distribution logic changes with every single click. Clicking the exact same button twice might alter just the image the first time, and completely overhaul both image and text the second time. Randomness and cascade dependencies are completely absorbed by the AI.

中文：
## 🎲 級聯鎖定與 AI 天然分流（語義分割）
系統的互動邏輯遵循嚴格的自上而下約束體系，並且完全在 LLM 的黑盒中動態處理。

* 級聯鎖定機制： 當使用者點擊「重抽 K」時，後端會強制鎖定隱藏陣列中從 1 到 K-1 的所有元素。系統只會針對第 K 到第 N 個元素進行重新亂數骰詞。K 越大，代表鎖定的前置上下文越多，付出的代價也越高。
* 動態語義分割： 每次重抽發生時，後端會把修改後的隱藏陣列丟回給 LLM。由 AI 在幕後動態決定：「這 N 個元素裡面，誰去繪圖提示詞（Image Prompt）、誰去社群文案（Caption）、誰兩邊都去？」
* 動態黑盒悖論： UI 畫面永遠長得一模一樣，但底層的分流邏輯每次點擊都在翻新。使用者連續點擊同一個按鈕兩次，第一次可能只改動了圖片細節，第二次卻可能同時顛覆了圖文。隨機性與級聯性完全由 AI 承擔。
